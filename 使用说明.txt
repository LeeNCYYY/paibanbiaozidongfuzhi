排班复制助手
=====================================
- 读取 .xls / .xlsx 排班表(单文件多工作表按月份),支持合并单元格
- 三页:文件导入(含备注) / 当月排班 / 当天排班(iOS 风格)
- 当天排班所见即所得:编辑框内容即复制内容;复制时日期/星期不带标题前缀
- 星期后自动显示法定节假日或二十四节气(当前内置 2026、2027 年),当月排班、当天排班顶部和复制文本同步展示;
  法定节假日期间每天显示节日名称;如与节气重合,法定节假日优先,不再重复显示节气
- 修改按日期记住,可还原;备注自动追加末尾
- 护学岗:由表头"值班组"列派生,只读(不能手改),固定排在所有条目之后
    早上护学岗 = 前一天值班组在"周期"表名册中的前三人
    下午护学岗 = 当天值班组在"周期"表名册中的前三人
  所以改某天的值班组,该天下午和第二天早上的护学岗会立即联动,并自动保存;
  第二天复制时用的就是联动后的结果。
  人名按"、"拆分(兼容 , ， ; ； / 空格 换行),按名单顺序跳过不在名册中的人;
  名册中命中不足 3 人时全取。未读到"周期"表名册时不派生护学岗人员。
  护学岗仅在国家法定工作日复制(按国务院放假通知;已内置 2026、2027);
  周六/周日、法定节假日放假期间不复制该列;
  调休上班的周末(2026:1/4、2/14、2/28、5/9、9/20、10/10;
  2027:1/31、2/14、5/8、9/26、10/9)照常复制。
  点护学岗的标签可临时切换"要不要复制"(只影响是否复制,不改人员)。
  样式与其它条目完全一致(同字号、同行高)。
- 自动匹配"备注"行:某列在当天那格的文字以"备注"开头时,该行不再用表头列名,
  标题统一变成"备注"(内容里重复的"备注"二字会自动去掉);
  无论该列在源表哪一列,当天排班页固定展示在最后一栏,复制时固定排在正文最后(后置备注之前)
- 值班室值守:从"值班组"名单第 1 人开始往后找,取第一个同时出现在"周期"工作表
  "值班组"列(在册名单)里的人,复制文本单独输出一行"值班室值守：姓名";
  当天排班页不展示该派生行,也不再把它缀在原值班组名单中;
  第 1 人不在"周期"表名单里就顺延到下一人,所以结果只会是当日本日值班组成员;
  名单里一个人都不在"周期"表名单里时不显示值守人员,护学岗两行也不加;
  表格里没有识别到"周期"工作表、或周期表名单为空时不加标记(避免标错),
  复制时会提示"未读到周期表名单";
  "周期"表里若没有"值班组"表头,默认把 A/B/C 三列的人员当作值班组名单
- 源表的"护学岗/护校岗"列:当天排班页不读取、不展示、不复制(已被派生的早上/下午两段取代);
  当月排班卡片仍按原表原样显示;如果源表没有护学岗/护校岗列,则不派生、不展示、不复制护学岗;
  如果护学岗/护校岗列存在但当天对应单元格为空,当天排班页不展示派生护学岗,复制时也跳过
- 其它源表列一律原样显示,都不隐藏
- 当月排班:每天一张卡片,长按卡片即复制当天排班内容(与"一键复制"同一套文本,含前置/后置备注)
- 点击底部"当月排班"进入页面或再次点击该标签时,自动滚动到当月排班顶部
- 解析器为纯 Java 自研(.xls BIFF8 + .xlsx),零第三方依赖,不崩溃
构建:
  set JAVA_HOME=E:\AndroidStudio\jbr
  E:\Gradle\gradle-8.11.1\bin\gradle.bat :app:assembleDebug
  APK: app/build/outputs/apk/debug/app-debug.apk
自检(可选,桌面 Java 即可,不需要模拟器):
  DesktopTest -selftest                                    人名拆分/名册内前三人 断言
  DesktopTest <表格.xlsx> <yyyy-MM-dd> [-out=报告.txt]      解析与护学岗派生检查
