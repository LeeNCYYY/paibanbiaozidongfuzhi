# 排班复制助手

排班复制助手是一款面向值班排班场景的 Android 工具。它可以读取 `.xls` / `.xlsx` 排班表，按月份展示每日安排，并生成格式统一的排班文本，减少人工整理和复制时的工作量。

> 最新安装包请从 [Releases](https://github.com/LeeNCYYY/paibanbiaozidongfuzhi/releases/latest) 下载。

## 主要功能

- 读取 Excel 97-2003 `.xls` 和 Office Open XML `.xlsx` 排班表。
- 支持单文件多工作表，按月份整理显示。
- 支持合并单元格、日期列、星期列和多个排班条目列。
- 提供“文件导入”“当月排班”“当天排班”三个页面。
- 当天排班内容可直接编辑，修改按日期自动保存。
- 一键复制当天排班，也支持长按当月卡片复制当天内容。
- 支持前置备注和后置备注，并在复制时自动加入对应位置。
- 自动识别以“备注”开头的特殊行，并统一显示为“备注”。
- 当月排班页再次点击底部“当月排班”时自动回到顶部。
- 生成复制文本时，值班组标签显示为 `值 班 组 ：`，用于对齐四字标签。

## 护学岗规则

护学岗人员由源表中的“值班组”列自动派生，只读展示，不保存为独立编辑项。

- 早上护学岗：取前一天值班组的名册内前三人。
- 下午护学岗：取当天值班组的名册内前三人。
- 只取“周期”工作表值班组名单中的人员，不在名册中的人自动跳过。
- 最多取三人；名册中有效人员不足三人时，全部取用。
- 人名支持使用 `、`、`,`、`，`、`;`、`；`、`/`、空格和换行分隔。
- 源表没有“护学岗”或“护校岗”列时，不派生、不展示、不复制护学岗。
- 源表存在护学岗列但当天单元格为空时，当天同样不展示、不复制。
- 周六、周日和法定节假日放假期间默认不复制护学岗；调休上班日照常复制。
- 点击护学岗标签可以临时切换该行是否复制，但不会修改派生人员。

## 值班室值守规则

值班室值守人员从当天“值班组”名单中派生：

- 从名单第一个人开始查找。
- 取第一个同时存在于“周期”工作表值班组名册中的人。
- 当天排班页面不展示该派生人员。
- 复制文本在值班组下方单独增加一行：`值班室值守：姓名`。
- 没有任何有效在册人员时不生成该行。

## 法定节假日与二十四节气

- 已内置 2026、2027 年国务院法定节假日及调休上班安排。
- 已内置 2026、2027 年二十四节气日期。
- 当月排班和当天排班页面显示格式：`星期六 立冬`。
- 复制文本格式：`星期六（立冬）`。
- 法定节假日期间，假期中的每一天都显示节日名称。
- 法定节假日与节气日期重合时，只显示和复制法定节假日名称。

## 使用方式

1. 下载并安装 Release 中的 APK。
2. 打开“文件导入”，选择 `.xls` 或 `.xlsx` 排班表。
3. 如需要，在“前置”或“后置”输入框中填写备注。
4. 在“当月排班”中查看整月安排，长按某天卡片可复制该天内容。
5. 在“当天排班”中查看或修改当天内容，点击“一键复制”生成最终文本。

推荐排班表包含以下结构：

- 明确的工作表名称或标题，以便识别月份和年份。
- 表头包含“日期”和“星期”。
- 多个排班条目列，例如“值班组”“带班领导”“备注”等。
- 如需派生护学岗和值班室值守，请提供“周期”工作表及其中的人员名册。

## 隐私说明

- 应用不申请网络权限，不包含上传、统计或联网接口。
- 导入的 Excel 文件不会被复制进应用内部目录，解析结果主要在内存中处理。
- 文件 URI、用户填写的前后备注以及用户修改过的排班内容会保存在应用私有的 `SharedPreferences` 中。
- 一键复制的内容会进入 Android 系统剪贴板。
- Android 系统的自动备份或设备迁移可能包含应用私有数据，请根据设备安全策略管理备份。
- 本仓库不会提交真实排班表、人员名单或联系方式。

## 构建环境

- JDK 17
- Android SDK 36
- Gradle 8.x
- 最低 Android 版本：Android 8.0（API 26）

构建 Debug APK：

```powershell
gradle :app:assembleDebug
```

输出路径：

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 桌面回归测试

桌面测试不依赖 Android 模拟器，可直接使用 JDK 运行。

```text
DesktopTest -selftest
DesktopTest <表格.xlsx> <yyyy-MM-dd> [-out=报告.txt]
```
