# 每日信息复制器 (DailySheetCopier)

这是一个为安卓手机设计的电子表格信息提取工具。

## 功能
1. **导入 Excel**: 支持 `.xls` 和 `.xlsx` 格式。
2. **自动识别**: 自动匹配今天的日期并展示对应的记录。
3. **一键复制**: 按照 `标题: 内容` 的格式将当日信息复制到剪贴板，方便转发到微信/钉钉等。
4. **全览模式**: 可以查看整个表格的内容。

## 使用说明 (开发者)
1. 使用 **Android Studio** (推荐 Hedgehog 2023.1.1 或更高版本) 打开此文件夹。
2. 等待 Gradle 同步完成。
3. 连接安卓手机或启动模拟器。
4. 点击 **Run** 安装应用。

## 技术细节
- **语言**: Kotlin
- **UI**: Jetpack Compose
- **解析库**: Apache POI
- **架构**: MVVM

## 注意事项
- 确保 Excel 表格的第一行是标题行。
- 日期识别逻辑会自动寻找包含今天日期（格式如 `yyyy-MM-dd` 或 `yyyy/MM/dd`）的单元格。
